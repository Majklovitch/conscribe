Project goals

Lean, not dependency-freeKeep the core small and readable; add a focused Composer package when a feature needs one. PHP 8.4+ with Monolog, Tracy, PHPMailer, scssphp, minify, psr/container.
Front-controller routingClean split between public/index.php and application logic via the Router.
Secure by defaultCSRF validation, XSS escaping (esc()), secure cookies and security headers on every view and endpoint.
Modular architectureOptional features live in self-contained modules under app/Modules/ (currently Auth).

Versioning

<major>.<minor>.<fixes/additions>major = breaking changes · minor = a new feature line (one roadmap phase) · third number = each fix or backward-compatible addition inside the line. Removals are deprecated first and only happen in a major.
